## 1. Plan d'apprentissage semaine par semaine

### PHASE 1 — Fondations (Semaines 1–3)

#### Semaine 1 — Culture IA & outils de base

| Élément | Détail |
|---------|--------|
| **Objectif** | Comprendre ce qu'est l'IA générative, comment fonctionne ChatGPT, et s'en servir efficacement |
| **Compétences** | Prompting basique, navigation GPT-4/Claude, vocabulaire IA essentiel |
| **Temps estimé** | 2h/jour |

**Actions concrètes :**
- Créer un compte ChatGPT Plus et Claude Pro
- Suivre le cours *AI For Everyone* (Andrew Ng, Coursera) — Modules 1 & 2
- Tester 10 prompts différents sur des tâches quotidiennes

---

#### Semaine 2 — Prompt Engineering appliqué au droit

| Élément | Détail |
|---------|--------|
| **Objectif** | Maîtriser la rédaction de prompts pour des tâches juridiques (résumé de contrats, analyse de clauses, rédaction d'actes) |
| **Compétences** | Prompt structuré, chain-of-thought, few-shot prompting |
| **Temps estimé** | 2h/jour |

**Actions concrètes :**
- Suivre *ChatGPT Prompt Engineering for Developers* (DeepLearning.AI)
- Créer un carnet de prompts juridiques personnels (Notion)
- Tester sur un vrai contrat : NDA ou CDI

---

#### Semaine 3 — RGPD & conformité IA

| Élément | Détail |
|---------|--------|
| **Objectif** | Comprendre les bases du RGPD et le cadre réglementaire de l'IA (AI Act européen) |
| **Compétences** | Notions RGPD, droits des personnes, obligations entreprises, risques IA |
| **Temps estimé** | 1h30/jour |

**Actions concrètes :**
- Suivre le cours RGPD sur Udemy (voir section cours)
- Lire le résumé officiel de l'AI Act (europa.eu)
- Créer une fiche de synthèse RGPD vs AI Act (2 pages max)

---

## 3. Roadmap de compétences

### Prompt Engineering

```
Niveau débutant → avancé

Basique         : Instruction simple, rôle system, format de sortie
Intermédiaire   : Few-shot prompting, chain-of-thought, contraintes
Avancé          : System prompt multi-rôle, RAG basique, itération de prompts
```

**Application directe au droit :** rédaction de contrats, résumés juridiques, recherche jurisprudentielle, génération de clauses types.

**Outils de référence :** ChatGPT-4o, Claude 3.5 Sonnet

---

### Outils IA (usage opérationnel)

| Outil | Usage principal | Niveau requis |
|-------|-----------------|---------------|
| ChatGPT-4o | Rédaction, analyse, Custom GPTs | Débutant |
| Claude 3.5 Sonnet | Analyse longue de documents (200k tokens) | Débutant |
| Perplexity AI | Recherche juridique augmentée avec sources | Débutant |
| Notion AI | Documentation, organisation de connaissances | Débutant |

---

### Automatisation no-code

**Make.com** (workflows complexes, multi-apps) :
- Déclencheurs (webhooks, formulaires, emails)
- Modules de transformation (filtres, routeurs, agrégateurs)
- Connexion OpenAI API

**Zapier** (automatisations simples) :
- Zaps en 2–3 étapes
- Intégrations natives (Gmail, Notion, Slack)

**Exemple de workflow complet :**
```
Client remplit formulaire (Tally)
  → Make récupère les données
  → GPT-4 génère un résumé personnalisé
  → Dossier créé dans Google Drive
  → Email de confirmation envoyé au client
```

---

### Bases API

- Comprendre : REST API, endpoint, méthode HTTP (GET/POST), JSON, clé API
- Savoir faire : un appel OpenAI API dans Make sans coder
- Ne pas faire : apprendre Python à ce stade (inutile pour 90% des cas d'usage)

## 4. Projets pratiques obligatoires (Portfolio)

### Projet 1 — Assistant d'Analyse de Contrats

| Critère | Détail |
|---------|--------|
| **Difficulté** | ⭐ Débutante |
| **Durée** | 1 semaine |
| **Stack** | ChatGPT-4o Custom GPT Builder (aucun code requis) |

**Description :**
Créer un Custom GPT capable d'analyser un contrat, identifier les clauses à risque, proposer des reformulations et détecter les clauses manquantes selon le type de contrat.

**Étapes :**
1. Rédiger un system prompt structuré (rôle, format de sortie, règles d'analyse)
2. Tester sur 3 types de contrats : CDI, NDA, contrat de prestation de service
3. Itérer sur le prompt selon les résultats obtenus
4. Publier le Custom GPT (accès restreint ou public)

**Résultat attendu :** Un GPT fonctionnel avec 3 exemples documentés avant/après analyse.

**Livrable portfolio :** Captures d'écran annotées + description du cas d'usage sur Notion/LinkedIn.

---

### Projet 2 — Workflow Automatisé d'Onboarding Client Juridique

| Critère | Détail |
|---------|--------|
| **Difficulté** | ⭐⭐ Intermédiaire |
| **Durée** | 1 semaine |
| **Stack** | Tally.so + Make.com + OpenAI API + Google Drive + Gmail |

**Description :**
Automatiser le processus d'onboarding d'un nouveau client dans un cabinet d'avocats : collecte d'informations → traitement IA → création de dossier → communication client.

**Étapes :**
1. Créer le formulaire client dans Tally.so (informations de base, type de litige, urgence)
2. Configurer Make.com pour récupérer les réponses via webhook
3. Appeler l'API OpenAI pour générer un résumé du dossier et une liste de pièces à fournir
4. Créer automatiquement un dossier Google Drive avec le résumé
5. Envoyer un email de bienvenue personnalisé via Gmail

**Résultat attendu :** Un workflow de bout en bout fonctionnel et documenté.

**Livrable portfolio :** Schéma Make annoté + vidéo démo Loom (3 min max).

---

### Projet 3 — Outil d'Audit RGPD Semi-Automatique

| Critère | Détail |
|---------|--------|
| **Difficulté** | ⭐⭐ Intermédiaire |
| **Durée** | 1 semaine |
| **Stack** | Typeform + Make.com + GPT-4 + PDF export (PDFMonkey ou similaire) |

**Description :**
Créer un outil d'audit RGPD clé-en-main pour TPE/PME : questionnaire d'évaluation de la conformité → analyse par IA → rapport PDF personnalisé avec recommandations.

**Étapes :**
1. Construire le questionnaire RGPD dans Typeform (30 questions structurées par thème)
2. Configurer Make.com pour recevoir les réponses
3. Rédiger le prompt GPT-4 pour générer un rapport structuré (score, risques, recommandations)
4. Générer un rapport PDF personnalisé via PDFMonkey ou similaire
5. Envoyer le rapport par email au répondant

**Résultat attendu :** Un outil utilisable immédiatement par un cabinet ou une entreprise, avec rapport PDF professionnel en sortie.

**Livrable portfolio :** Lien démo (accès partagé) + exemple de rapport PDF anonymisé.

## 6. Erreurs à éviter absolument

| # | Erreur | Correction |
|---|--------|------------|
| 1 | **Vouloir tout apprendre avant d'agir** | Commencer les projets dès la semaine 7, pas après |
| 2 | **Se noyer dans les cours** | Maximum 7 cours ciblés ; le reste vient de la pratique |
| 3 | **Ignorer LinkedIn** | C'est le canal de recrutement #1 en Legal Tech — poster dès la semaine 4 |
| 4 | **Apprendre Python inutilement** | Le no-code couvre 90% des besoins à ce stade |
| 5 | **Sous-estimer son profil juridique** | La rédaction et l'analyse sont des compétences rares chez les profils tech |
| 6 | **Attendre d'être "prêt(e)"** | Proposer des missions dès le projet 1 terminé |
| 7 | **Négliger la veille** | L'IA évolue vite — 15 min/jour sur LinkedIn + newsletters suffit |

2. **Enseigner pour comprendre** : expliquer à voix haute ou rédiger un post LinkedIn ce qu'on vient d'apprendre
3. **Utiliser l'IA pour apprendre l'IA** : demander à ChatGPT de créer des quiz, corriger des exercices, expliquer différemment
4. **Rejoindre une communauté** : Discord "AI Lawyers", groupes LinkedIn Legal Tech France
5. **Itérer vite** : un projet imparfait terminé vaut 10 projets parfaits non commencés
